# Bank_OOP

🔐 **Simulation d’un système bancaire en C++ avec Programmation Orientée Objet (POO)**

Ce projet est une application console qui reproduit le fonctionnement d’un système bancaire moderne.  
Il intègre la gestion des clients, des comptes, des transactions, un système d’authentification sécurisé, et même un module de conversion de devises.

---

## 🚀 Fonctionnalités

- 👤 **Gestion des clients** : création, modification, suppression et recherche  
- 💳 **Opérations bancaires** : dépôts, retraits, transferts entre comptes  
- 🔐 **Authentification sécurisée** : connexion via identifiant et mot de passe  
- 📜 **Historique des opérations** : journalisation des transactions effectuées  
- 💱 **Conversion de devises** : calculateur intégré pour les échanges monétaires  
- 🖥️ **Interface console** : menus interactifs simples et intuitifs  

---

## 🏗️ Architecture & Conception

Le projet est construit autour de classes principales, chacune représentant une entité du système :

- `Client`  
- `Compte`  
- `Transaction`  
- `Utilisateur`  
- `Devise`  

Chaque classe gère ses propres données et comportements, garantissant :
- **Modularité**  
- **Réutilisabilité**  
- **Facilité de maintenance**
